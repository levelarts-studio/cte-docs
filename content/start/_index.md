# Getting Started with the CTE Library

Welcome to the **Level Arts CTE Module Library**. This site hosts technical modules, assignment specs, and standards coverage for Media & Game Art pathways.

## How This Site Works

- **Modules (`/learn/`)**: Decoupled textbook lessons. Each module teaches one specific skill or concept.
- **Course Maps (`/courses/`)**: Ordered unit schedules for Intro to Media Careers (IMC), Game Art & Design 1 (GAD1), and Game Art & Design 2 (GAD2).
- **Assignments (`/assignments/`)**: Required student projects. Submit your work via Google Classroom.

## Portfolio & Software Setup

1. **Google Sites Portfolio**: Follow [CAREER-104](/learn/career/building-a-google-sites-portfolio/) to set up your public portfolio site.
2. **Google Classroom**: All due dates, gradebook entries, and turn-in links live in Google Classroom.
3. **Blender**: Download Blender 4.x from [blender.org](https://www.blender.org/).
4. **Unreal Engine**: Install Unreal Engine 5.x via the Epic Games Launcher.
