Welcome to the **AED Module Library** (Arts, Entertainment, & Design). This site serves as a decoupled curriculum repository housing **144 textbook modules**, **50 student assignment specs**, **178 Model Curriculum Standards (MCS)**, and **3 complete course maps**.

{{< callout type="info" >}}
**Quick Keyboard Shortcut**: Press <kbd>Ctrl + K</kbd> (or <kbd>Cmd + K</kbd> on Mac) anywhere on the site to open instant search across all lessons, tools, standards, and keywords.
{{< /callout >}}

## Site Navigation & Structure

The AED Module Library is organized into four core pillars:

### 1. Textbook Module Library
Decoupled instructional modules organized by subject area and skill tier level. Each module focuses on core concepts, terminology, and hands-on skill development:
- [Blender 3D](/learn/blender/) — 3D modeling, UV unwrapping, PBR texturing, retopology, and game export.
- [Unreal Engine 5](/learn/unreal/) — Actor placement, materials, Lumen lighting, Blueprint logic, and level assembly.
- [Game Design & Mechanics](/learn/gamedesign/) - Core loops, level design, player affordances, mechanics, and balancing.
- [Design & Visual Craft](/learn/design/) - Elements of art, principles of design, color theory, and composition.
- [Media & Storytelling](/learn/media/) - Narrative structure, shot types, framing, editing cuts, and sound design.
- [Production & Pipelines](/learn/production/) - Production phases, briefs, GDDs, version control, and task boards.
- [Computing & PC Literacy](/learn/computing/) - Hardware fundamentals, operating systems, and file management.
- [Career & Portfolio](/learn/career/) - CTE pathways, O*NET research, and Google Sites portfolios.
- [Law, Ethics & AI](/learn/law/) - Copyright, fair use, open licenses, and generative AI ethics.

### 2. Required Assignment Specs
Practical lab specs and portfolio deliverables ([View All Assignments](/assignments/)). Each spec outlines clear task objectives, prerequisite modules, execution steps, Google Sites submission instructions, and standard rubrics.

### 3. Course Maps
Sequenced pathways showing how modules and assignments build upon each other across active course tracks:
- [Intro to Media Careers (IMC)](/courses/imc/) — Digital foundations, design principles, media production, and career literacy.
- [Game Art & Design 1 (GAD1)](/courses/gad1/) — 3D modeling, PBR pipelines, Unreal Engine logic, and solo vertical slice.
- [Game Art & Design 2 (GAD2)](/courses/gad2/) — Technical art, retopology, systems design, and capstone project.

### 4. Model Curriculum Standards (MCS) Index
California Model Curriculum Standards index for Arts, Media, and Entertainment ([View Standards Index](/standards/)). Every module and assignment is tagged with specific standard codes (e.g. `AV.17.1`).
