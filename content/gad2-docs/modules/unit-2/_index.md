  Advanced Environment Art (Hero Scene)
</div>

Characters live in worlds. In this unit, students create a single, high-fidelity "Hero Scene" in Unreal Engine 5. This is not a whole level—it is a single camera angle perfect composition, optimized for ArtStation.

{{< callout type="info" >}}
This is the "Environment Artist" specialization track. If a student prefers Character Art, they can do a second character study here, but must still learn the lighting/rendering tools in Unreal.
{{< /callout >}}

---

## Topics Covered

- **Composition**: Rule of Thirds, Leading Lines, Golden Ratio.
- **Advanced Texturing**: Trim Sheets and Tileables vs Unique Bakes.
- **Foliage**: Creating trees and grass that blow in the wind.
- **Shaders**: Master Materials, Vertex Painting, and Puddles.
- **Lighting**: Lumen, Raytracing, and Post-Process Volumes.

## Learning Report

**Objectives**

- Plan a scene using a greybox and lighting first.
- Create a Trim Sheet to texture multiple assets efficiently.
- Model and scatter foliage using Unreal's foliage tools.
- Create a Master Material with "Parameters" (Wetness, Dirt, Color).

**Materials**

- Unreal Engine 5.
- Blender.
- Photoshop/Substance.

**Standards Alignment**

- **10.3** — Visualize ideas through sketches, turnarounds, and modeling
- **4.3** — Use job-specific hardware/software for workflows and content delivery
- **4.5** — Apply rendering and exporting techniques to meet standards
