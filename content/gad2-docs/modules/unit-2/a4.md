## 🎥 Video Outline

- **Master Materials**
  - Don't make a new material for every object.
  - Make ONE material, and using "Material Instances" to change color/roughness.
- **Vertex Painting**
  - Blending between two textures (e.g., Brick and Plaster) using vertex colors.
