You will work in **teams** to deliver a game concept package and a **first playable demo**. This project connects directly to **Year 3, Semester 1** units:  
- **Unit 1 — Project Planning & Concept Development**  
- **Unit 2 — Core Asset Creation**  
- **Unit 3 — World Assembly & First Playable**  

Your team’s project should establish a clear **vision, scope, and first playable build** that communicates mood, navigation, and story through the environment.  

> [!NOTE]  
> Every team member shares the **same grade** for the group project deliverables. However, each student must also submit an **individual Project Overview Document** that explains their contributions and reflections.

---

# Deliverables

Submit one complete **Team Concept Package** that includes:

1. **Game Design Document (GDD)**  
   - Vision, genre, goals, and scope.  
   - Core mechanics and target player experience.  
   - Breakdown of team roles and responsibilities.  

2. **Art Style Guide + Visual Targets**  
   - Palette, references, mood boards.  
   - Example props, textures, or inspirations that define tone.  

3. **Core Assets**  
   - A small set of major props or modular kit pieces created in Blender.  
   - Clean topology and consistent scale, tested in Unreal.  

4. **First Playable Demo**  
   - Blockout environment with major key props in Unreal.  
   - Basic lighting and post-processing for readability and mood.  
   - Navigation and environmental storytelling checks.  

5. **Presentation Board + Team Presentation**  
   - One clean board summarizing the concept, visual style, and first playable.  
   - Group presentation to the class with milestone build walkthrough.  

6. **Individual Project Overview Document (2–3 pages)**  
   - Description of your personal contributions.  
   - Reflection on collaboration and production process.  
   - Self-assessment of strengths, challenges, and next steps.  

> [!WARNING]
This is a team project. All members receive the same grade for the final deliverables. Your performance depends on the strength of the group’s work, not just individual effort.

## Learning Outcomes

By completing this project, you will:  
- Practice **team-based project planning** with a GDD and style guide.  
- Create **core game assets** and integrate them into Unreal.  
- Deliver an **early playable demo** with environmental storytelling.  
- Communicate your **individual role and contributions** in writing.  
- Prepare for **Semester 2 vertical slice production**.

## Submission Format

- Team folder labeled: `TeamName_FinalProject1.zip`  
- Subfolders:  
  - `01_GDD/` → game design document, team roles  
  - `02_StyleGuide/` → palettes, mood boards, references  
  - `03_Assets/` → Blender models + FBX exports  
  - `04_UnrealBuild/` → packaged build of first playable demo  
  - `05_Presentation/` → board + slides  
- Individual file (submitted separately by each student):  
  - `Last_First_ProjectOverview.pdf`

## Rubric (100 pts)

| Criteria | Excellent | Adequate | Weak | Value |
|----------|-----------|----------|------|------:|
| **GDD & Team Planning** | Clear scope, complete roles | Basic plan, minor gaps | Vague or missing | 15 |
| **Art Style Guide & Visual Targets** | Cohesive, detailed boards | Some references, basic clarity | Minimal or unfocused | 15 |
| **Core Assets** | Clean models, scaled, functional in Unreal | Some issues, but usable | Incomplete or non-functional | 20 |
| **First Playable Demo** | Clear layout, mood, navigation | Present but rough | Incomplete or confusing | 25 |
| **Presentation & Board** | Polished, professional | Basic but functional | Rushed or unclear | 10 |
| **Individual Overview Document** | Detailed, reflective, clear role | Basic description | Minimal or unclear | 15 |

*Late work: −10% per week. Missing individual overview: −15 pts.*
