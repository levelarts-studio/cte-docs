You will create a **Vertical Slice Alpha Build** that integrates your team’s character, environment, and mechanics into a working scene in Unreal Engine. This project connects directly to **Year 3, Semester 1** units:  
- **Unit 1 — Narrative Design & Game Design Document**  
- **Unit 2 — Team Pitch & Pre-Production**  
- **Unit 3 — Prototyping & Outlining Learning Objectives**  
- **Unit 4 — Vertical Slice Build (Alpha)**  

Your Alpha build must demonstrate that the project is **playable from start to finish**, even if art and polish are incomplete. Focus on function and collaboration.

> An **Alpha build** is not polished. It is your chance to prove that your vertical slice works: core mechanics, basic interactions, and a playable loop.

# Steps to Completion

{{% steps %}}

### Step 1 — Project Setup  
Create a shared Unreal Engine project.  
Set up version control or agreed team workflow (naming conventions, folders).  

### Step 2 — Asset Integration  
Import your team’s characters, props, and environment blockouts.  
Place them in the level and confirm scale and alignment.  

### Step 3 — Core Gameplay Loop  
Implement navigation, interactions, and at least one win condition.  
Ensure the game can be played start to finish.  

### Step 4 — Internal Playtesting  
Run multiple playtests within your team.  
Log bugs, balance issues, and unclear interactions.  

### Step 5 — Alpha Build Package  
Package the Unreal project and create a playable build.  
Capture screenshots and record a short (30–60 sec) video walkthrough.  

### Step 6 — Documentation & Portfolio  
Submit a **Debug Report** with bugs and fixes planned.  
Upload build, screenshots, video, and reflection to your portfolio.  

{{% /steps %}}


# Deliverables

- Packaged Alpha build (Unreal project + executable)  
- Debug/playtest report with identified issues and fixes  
- Screenshots and short playthrough video  
- Team production documentation (roles, tasks completed)  
- Portfolio entry with reflection on challenges and progress

## Learning Outcomes

By completing this project, you will:  
- Apply **team-based workflows** in Unreal Engine  
- Deliver a playable **Alpha build** with core mechanics functioning  
- Practice **debugging, playtesting, and iteration**  
- Document and reflect on **production processes**  
- Prepare for the **Beta build + marketing package** in Semester 2  

## Submission Format

- Folder labeled: `TeamName_VerticalSliceAlpha.zip`  
- Subfolders:  
  - `01_Project/` → Unreal project folder  
  - `02_Build/` → packaged playable build  
  - `03_Renders/` → screenshots + walkthrough video  
  - `04_Documents/` → debug/playtest report + portfolio PDF  


## Rubric (100 pts)

| Criteria | Excellent | Adequate | Weak | Value |
|----------|-----------|----------|------|------:|
| **Core Gameplay Loop** | Fully functional, playable start-to-finish | Mostly functional, minor gaps | Broken/incomplete | 25 |
| **Asset Integration** | Character, props, and environment working together | Most assets working, some issues | Many missing or broken | 20 |
| **Playtesting & Debugging** | Thorough report, bugs identified, fixes planned | Report present, some gaps | Minimal/no report | 15 |
| **Documentation & Portfolio** | Complete with screenshots, video, reflection | Partial or missing pieces | Minimal submission | 15 |
| **Team Collaboration** | Roles clear, tasks documented, deadlines met | Some evidence of teamwork | Poor/no collaboration | 15 |
| **Professional Practices** | Organized folders, correct naming, credits shown | Minor errors | Disorganized | 10 |

*Late work: −10% per week. Missing sources/references: −5 pts. Poor naming/organization: −2 pts.*
