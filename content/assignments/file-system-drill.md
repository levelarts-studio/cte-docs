## The task

Build a proper folder structure in your Google Drive for this class, and populate it with files named the right way. This is the structure you'll actually use for every assignment this year, so set it up once, correctly, now.

**Deliverable**: Organized project directory screenshot posted to your portfolio Coursework page + reflection write-up.

## Before you start

- [Files, Folders, and Paths](/learn/computing/files-folders-and-paths/) (`COMP-103`) — folder hierarchies, directory paths, and file extensions
- [Naming Conventions](/learn/computing/naming-conventions/) (`COMP-105`) — version numbers, underscores, and avoiding special characters

## Steps

{{% steps %}}

### Step 1 — Build your top-level folder

In your Google Drive, create one folder for this class:

```text
IMC/
```

### Step 2 — Build the structure inside it

Inside `IMC`, create these folders:

```text
IMC/
  01_Assignments/
  02_Reference/
  03_Exports/
```

The numbers keep the folders in this order rather than shuffling alphabetically as you add more.

### Step 3 — Create project subfolders

Inside `01_Assignments`, make one subfolder per unit so far:

```text
01_Assignments/
  Unit1_DigitalFoundations/
  Unit2_DesignFundamentals/
```

You'll add a new one as each unit starts.

### Step 4 — Practice the naming convention

Inside `Unit1_DigitalFoundations`, create three placeholder files using the naming pattern from the reading. They can be empty Google Docs; the point is the names, not the content.

```text
YOURNAME_PortfolioNotes_v01
YOURNAME_WorkstationPhoto_v01
YOURNAME_FileDrillNotes_v01
```

### Step 5 — Test what breaks

As a deliberate experiment, try creating a file with a space and a special character in the name, something like `My Final Notes?.docx`. Take a screenshot of what happens: does Drive allow it, rename it, or block it? You're confirming what the reading described, not guessing.

Then rename it correctly using the convention.

### Step 6 — Screenshot your structure

Capture a screenshot showing the full folder tree expanded: `IMC` down through both unit subfolders, with all filenames visible and readable.

### Step 7 — Write it up

Post to your Coursework page using the standard write-up format, plus:

- Your folder structure screenshot
- Your special-character test screenshot and what happened
- **In your own words:** why version numbers use two digits instead of one
- **In your own words:** one real problem a space in a filename can cause

Explaining it in your own words is what shows you understood it, not just followed the steps.
