  Final Project Rubric

You will expand your **Semester 1 Hero Prop** into a **small playable environment** in Unreal Engine. This project connects to:  
- **Unit 4 — Unreal Engine Setup & Asset Import**  
- **Unit 5 — Environment Design & Level Assembly**  
- **Unit 6 — Final Environment Project**  

Your environment should **tell a story through space**: the placement of your hero prop, surrounding architecture, terrain, lighting, and atmosphere. Add at least one **interactive element** (ex: a door that opens, a light switch, or a simple particle effect).  

> [!NOTE]  
> This is your **capstone for Year 2**. It combines 2D/3D workflow, environment design, and Unreal integration into one final package.

---

# Deliverables

Submit one complete **Environment Package** that includes:

1. **Environment Narrative (200–300 words)**  
   - How the hero prop defines the space and story.  
   - Intended mood or theme (sacred, abandoned, futuristic, etc.).  
   - Player experience: what should they notice first, and why?  

2. **Design Docs**  
   - Sketches or blockouts showing layout and scale.  
   - Callouts for lighting, focal points, and prop placement.  

3. **Unreal Project Build**  
   - Imported hero prop with correct materials.  
   - Small environment with terrain or architecture.  
   - One interactive element (Blueprint).  
   - Organized folders, named assets, clean project.  

4. **Visual Output**  
   - 3–5 high-quality screenshots (beauty shots + wide view).  
   - One short walkthrough video (30–60s, exported from Unreal).  

5. **Presentation Board + Process PDF**  
   - Board with narrative, key images, and layout notes.  
   - PDF documenting blockout → assembly → lighting → final, with credited references.

## Learning Outcomes

You will:  
- Apply **environment design principles** (composition, scale, focal points).  
- Demonstrate **Unreal Engine workflows** from import to final render.  
- Show **basic interactivity** using Blueprints.  
- Build a portfolio piece combining **2D planning, 3D assets, and real-time rendering**.  

## Submission Format

- Folder labeled: `Last_First_Environment.zip`  
- Subfolders:  
  - `01_DesignDocs/` → sketches, blockouts, notes  
  - `02_UnrealProject/` → `.uproject` with organized assets  
  - `03_Renders/` → screenshots, walkthrough video  
  - `04_Documents/` → narrative + process PDF  

## Rubric (100 pts)

| Criteria | Excellent | Adequate | Weak | Value |
|----------|-----------|----------|------|------:|
| **Narrative** | Clear story + space purpose | Basic description | Vague or none | 10 |
| **Design Docs** | Complete, clear scale + layout | Some sketches/blockouts | Minimal work | 15 |
| **Environment Build** | Clean, organized, polished | Functional but rough | Incomplete | 30 |
| **Lighting & Interactivity** | Strong mood + working Blueprint | Basic lighting, partial interactivity | Weak or none | 20 |
| **Visual Output** | Polished renders + clear video | Present but rough | Poor readability | 15 |
| **Process & Professionalism** | Complete doc, references credited | Some missing | None | 10 |

*Late work: −10% per week. Missing references: −5 pts. Poor naming: −2 pts.*
