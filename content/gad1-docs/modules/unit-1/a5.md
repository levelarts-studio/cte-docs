- **Export Settings for Unreal**

  - Format: **FBX**
  - Scale: **1.0** (1 Blender unit = 1 meter)
  - **Forward**: **-X Forward**
  - **Up**: **Z Up**
  - Apply modifiers, export **selected objects only**
  - Armatures: Turn OFF leaf bones
  - Units: Unreal reads 1 meter as 100 Unreal units (centimeters)

- **Testing the Export**

  - Re-import your FBX back into Blender to check scale and orientation.
  - Optional: Test import into Unreal to confirm correct alignment.

- **Portfolio Presentation**
  - Renders: front, side, perspective, and wireframe.
  - A simple 30–60 second turntable animation.
  - Reflection paragraph: what worked, what you struggled with, what you learned.

## ⌨️ Hotkeys to Remember

- **Ctrl + A** → Apply transforms (rotation, scale, location)
- **F12** → Render image
- **Ctrl + F12** → Render animation (turntable)
- **Alt + Z** → Toggle X-Ray for checking geometry
- **Shift + Space, V** → Quick switch to viewport shading modes

## 🛠️ Workshop Goals

**Workshop 1**

- Apply transforms and finalize naming.
- Export character as FBX with correct settings.
- Re-import FBX into Blender to confirm orientation/scale.
- Start setting up studio lighting for renders.

**Workshop 2**

- Render orthographic and perspective views with wireframe overlay.
- Render a 30–60 sec turntable animation.
- Write a 150–200 word reflection on the modeling process.
- Upload all files to Canvas and add a portfolio entry.

_If you finish early:_

- Test importing your FBX into Unreal for a scale check.
- Pose your character in a simple stance for extra renders.

## 📑 Deliverables

- **Blender Project File (.blend)** with final base mesh
- **Exported FBX** with correct orientation and naming
- **Rendered Images** (front, side, perspective, wireframe)
- **Turntable Animation** (30–60 sec)
- **Reflection Paragraph**
- Upload to **Canvas** and **Portfolio** as:  
  **“Character Modeling I — Export & Portfolio Upload”**
