## 🎥 Video Outline

- **From Blockout to Base Mesh**  
  - Transition from primitives to refined shapes.  
  - Focus on *proportion accuracy* and *readable silhouette*.  

- **Key Anatomy Landmarks**  
  - Shoulders, elbows, knees, hips, ribcage, jawline.  
  - Use landmarks to check scale and flow of the model.  

- **Refining Workflow**  
  - Use scaling, edge loops, and proportional editing to adjust forms.  
  - Keep everything low-poly — detail comes later.  
  - Constantly check silhouette from front, side, and ¾ view.  

- **Tips for Accuracy**  
  - Compare model against reference images every few minutes.  
  - Look at real anatomy references in addition to your turnaround.  
  - Don’t chase perfection — aim for clarity and balance.

## ⌨️ Hotkeys to Remember

- **Ctrl + R** → Add loop cut (for edge loops)  
- **O** → Toggle proportional editing  
- **Alt + Left Click** → Select edge loop  
- **Shift + Tab** → Toggle X-Ray / wireframe view  
- **Ctrl + A → Apply Scale** (important for accurate proportions)  
- **Shift + D** → Duplicate mesh part if needed  

## 🛠️ Workshop Goals  

**Workshop 1**  
- Review blockout mesh from A1.2.  
- Adjust overall body proportions to align with reference sheets.  
- Add edge loops to mark major anatomy landmarks.  
- Use proportional editing to smooth transitions.  

**Workshop 2**  
- Refine shapes for torso, limbs, and head.  
- Ensure silhouette matches turnaround from Unit 1.1.  
- Save `.blend` file and export WIP screenshots.  
- Start prepping mesh for topology cleanup (A1.4).  

*If you finish early:*  
- Add very rough placeholders for hands/feet to test proportions.
