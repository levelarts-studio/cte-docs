  Intermediate Prop Modeling & UV Mapping
</div>

In this unit, students go beyond the basics to model more complex game props with clean topology. Emphasis is placed on **hard-surface modeling techniques**, keeping meshes efficient for games, and preparing them for textures through proper UV unwrapping.

{{< callout type="info" >}}
This unit builds on **Blender fundamentals** and introduces the industry-standard workflow of UV mapping. By the end, students will have produced a clean, low-poly prop with a functional UV layout, ready for texturing.
{{< /callout >}}

## Topics Covered
- Hard-surface modeling tools (bevel, mirror modifier, edge loops)  
- Maintaining clean topology (quads, avoiding ngons, efficient polycount)  
- Low-poly asset standards for games  
- UV unwrapping basics (seams, islands, scaling, packing)  
- Applying test textures to check UVs

## Learning Report

**Objectives**  
- Apply hard-surface modeling techniques to create detailed props  
- Maintain clean, efficient topology appropriate for games  
- Demonstrate proper UV unwrapping with packed islands  
- Prepare assets for texturing in the next unit  

**Materials**  
- Classroom computer with Blender installed  
- Notebook or digital sketches for planning prop designs  

**Assessment**  
Students demonstrate skill by modeling an intermediate prop (e.g., lamp, toolbox, weapon, or chair) with clean topology and a properly unwrapped UV map. Evaluation is based on technical correctness and readiness for texturing, not on complexity.  

**Activities**  
Students follow demonstrations to model a prop, practice optimization, and unwrap UVs. Independent labs reinforce skills through repeated unwrap practice. Final assignment includes a completed prop with UV layout preview.
