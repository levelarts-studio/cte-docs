  Texturing, Lighting & Export Pipeline
</div>

In this unit, students learn how to bring props to life with textures, lighting, and proper export settings for game engines. Focus is placed on creating efficient textures, baking key maps, presenting props with lighting setups, and preparing assets for Unreal Engine.

{{< callout type="info" >}}
This unit bridges the gap between **modeling and presentation**. By the end, students will have a fully textured, lit, and exported prop suitable for use in Unreal.
{{< /callout >}}

## Topics Covered
- Creating and applying textures in Blender (diffuse, roughness, metallic)  
- Baking normal maps and ambient occlusion maps  
- Setting up lighting rigs for clear renders  
- Rendering props for portfolio presentation  
- Export settings for Unreal Engine (FBX best practices)

## Learning Report

**Objectives**  
- Create and apply textures to props in Blender  
- Bake normal and ambient occlusion maps for added detail  
- Use lighting setups to present props clearly and professionally  
- Export game-ready assets for Unreal Engine  

**Materials**  
- Classroom computer with Blender installed  
- Starter prop model from Unit 2 with clean topology and UVs  

**Assessment**  
Students demonstrate mastery by texturing and lighting a low-poly prop, baking maps, and exporting it cleanly for Unreal. Assessment is based on technical execution and readiness for the next semester’s environment work.  

**Activities**  
Students will create basic textures, practice baking workflows, experiment with lighting, and render portfolio-ready images of their props. Final submission includes a Blender render, baked maps, and an exported FBX file tested in Unreal.
