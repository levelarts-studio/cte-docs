  Character Modeling I (The Base Mesh)
</div>

This is the big one. Students will spend this unit modeling a **Humanoid Character** from scratch. We start with the base mesh—focusing on edge loops, anatomy, and clean topology. By the end, they will have a "Greybox" character ready for sculpting.

{{< callout type="info" >}}
Character modeling is hard. It requires patience. We will use the **box modeling** method (extruding from a cube) as it is the most beginner-friendly way to understand 3D space.
{{< /callout >}}

## Topics Covered

- **Anatomy**: Proportions, Muscle Groups, Landmarks.
- **Topology**: Why face loops matter (for animation).
- **Modeling Hands**: The hardest part (we save it for the middle).
- **Clothing**: Modeling simple clothes on top of the body.
- **UV Unwrapping**: Unwrapping infinite organic shapes.

## Learning Report

**Objectives**

- Model a humanoid body with correct proportions.
- Create a functional hand and face with animation-ready topology.
- Model clothing that fits the character.
- Unwrap the entire character UVs.

**Materials**

- Character Reference Sheet (Use the one created in Year 1 or find a new one).
- Blender.

**Standards Alignment**

- **10.3** — Visualize ideas through sketches, turnarounds, and modeling
- **17.5** — Model digital characters and create orthographic/turntable views
- **18.2** — Understand artist workflows for modeling and anatomy forms
