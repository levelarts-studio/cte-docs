## 🎥 Video Outline

- **Extracting Geo**
  - Select the body faces -> Shift+D (Duplicate) -> P (Separate).
  - Scale up slightly (Alt+S) to create thickness.
- **Modeling Straps/Belts**
  - Using Curves to wrap around the body.
- **Hard Surface Accessories**
  - Adding armor plates, pouches, or shoes.

## 🛠️ Workshop Goals
