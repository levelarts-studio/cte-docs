  - Primary, Secondary, Tertiary.

  - **Red**: Danger, Passion, Heat.
  - **Blue**: Calm, Sadness, Tech.

## 🛠️ Workshop Goals

- Create a new Canva design.
- Create 3 distinct color palettes (5 colors each):
  1. **"Calm & Serene"** (Blues, pastels).
  2. **"Danger & Action"** (Reds, high contrast).
  3. **"Magic & Mystery"** (Purples, darks).
- Label each palette with its name and the Hex codes for each color.
