  Story & Pre-Production
</div>

Before a single pixel is placed in a game engine or a camera starts rolling, the story must be told. In this unit, students learn the fundamentals of narrative structure and pre-production. They will develop an original concept, plan the visuals, and storyboard the action.

{{< callout type="info" >}}
This unit focuses on **narrative design** and **planning**. Good planning saves time and money in production!
{{< /callout >}}

## Topics Covered

- **Narrative Structure**: The Hero's Journey and Three-Act Structure.
- **Concept Development**: Writing a "High Concept Hook".
- **Visual Planning**: Creating Mood Boards and Shot Lists.
- **Storyboarding**: Translating script to visual panels.
- **Cinematography**: Understanding shot types (Close Up, Wide, Over the Shoulder).

## Learning Report

**Objectives**

- Analyze the narrative structure of a story using the Hero's Journey.
- Develop an original High Concept for a game or film.
- Curate visual references into a cohesive Mood Board.
- Define camera shots and angles using industry terminology.
- Create a clear, sequential storyboard for a scene.

**Materials**

- Google Docs (Writing).
- Canva (Mood Board).
- Krita (Storyboarding).

**Standards Alignment**

- **2.2** — Use industry-appropriate terminology when presenting work
- **10.3** — Visualize ideas using storyboarding and iterative methods
- **10.2** — Use research, imagery, and inspiration to generate concept ideas
