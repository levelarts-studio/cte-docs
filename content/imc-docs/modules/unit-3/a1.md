  Assignment 3.1 — Introduction to Krita

This week you'll learn **Krita**, a free and powerful digital painting application used by concept artists worldwide. You'll explore the interface, tools, and basic workflows.

## What is Krita?

Krita is free, open-source digital painting software designed specifically for concept art, illustration, and texture creation. It's industry-standard for pre-production art and will be your primary tool throughout Year 1.

**Download**: [krita.org](https://krita.org)

## Assignment Directions

### Part 1: Interface Exploration

Install Krita and complete these tasks:
1. Open Krita and create a new document (1920x1080px, 300 DPI)
2. Explore the interface: toolbox, brush presets, layers panel, color selector
3. Test at least 5 different brushes from the brush presets
4. Create 3 layers and practice organizing them
5. Save your file as a .kra (Krita format)

Document your exploration with 2-3 screenshots showing the interface.

### Part 2: Basic Tool Practice

Create simple exercises to learn fundamental tools:
1. **Line Practice**: Draw 10 straight lines, 10 curved lines, varying pressure
2. **Shape Practice**: Draw circles, squares, triangles using freehand brushes
3. **Value Practice**: Create a 5-step value scale from black to white
4. **Layer Practice**: Create a simple scene with 3+ layers (background, midground, foreground objects)

Save all exercises in one Krita file with organized layers.

### Part 3: Digital Drawing Comparison

Write a short reflection (150-200 words):
- How does digital drawing in Krita feel compared to traditional drawing?
- What tools or features surprised you?
- What challenges did you encounter?
- How might Krita help you develop your capstone concepts?

## What to Turn In

Submit to Canvas:
1. Screenshots of Krita interface exploration (2-3 images)
2. Krita file (.kra) with all basic tool exercises
3. Reflection on digital drawing (150-200 words)

## Grading Criteria

- **Interface Exploration** (30%): Screenshots show understanding of workspace
- **Tool Practice** (50%): Exercises completed, file organized with layers
- **Reflection** (20%): Thoughtful comparison and self-awareness

## Resources

- **Krita Tutorials**: [docs.krita.org/en/tutorials](https://docs.krita.org/en/tutorials)
- **YouTube**: Search "Krita for beginners" for video guides
- **Keyboard Shortcuts**: B = brush, E = eraser, Ctrl+Z = undo
