<div class="hx:mt-1 hx:text-gray-500 hx:text-lg">
  Assignment 4.4 — Creating Your Visual Style Guide
</div>

A visual style guide (or "art bible") documents all visual decisions for a project. This week, you'll create a comprehensive style guide in Canva.

## What Goes in a Style Guide?

- Character designs with color
- Prop designs with color
- Environment concepts and color palettes
- Mood boards and reference images
- Typography and graphic elements (if applicable)
- Notes on style, mood, and visual direction

## Assignment Directions

### Part 1: Add Color to Concepts

In Krita, add color to your character and prop concepts from Unit 3:
- Use the color palettes you developed in A4.2
- Keep it clean—flat colors or simple shading
- Export as PNG files for use in Canva

### Part 2: Build Style Guide in Canva

Create a multi-page style guide document (8-12 pages) including:
1. **Cover page**: Project title and your name
2. **Overview**: 1 paragraph describing the project
3. **Mood board**: From A4.3
4. **Color palettes**: Character and environment palettes
5. **Character design**: Colored concept with notes
6. **Prop design**: Colored concept with notes
7. **Environment concepts**: Sketches, colors, key features
8. **Style notes**: Overall visual direction, inspirations

Make it professional, organized, and visually cohesive.

### Part 3: Peer Review

Share your style guide with 2 classmates and gather feedback:
- Is the visual direction clear?
- Are the designs cohesive?
- What's working well?
- What could be improved?

Document the feedback you received.

## What to Turn In

1. Colored character and prop concepts (Krita files or images)
2. Complete visual style guide (Canva PDF or link)
3. Peer feedback summary (100-150 words)

## Grading Criteria

- **Colored Concepts** (25%): Effective color application
- **Style Guide** (55%): Comprehensive, professional, well-organized
- **Peer Feedback** (20%): Documentation of review process

**Standards Addressed**: 4.2 (Communication tech), 10.3 (Visualizing ideas), 2.6 (Presentation), 9.1 (Collaboration)
