  Assignment 4.1 — Color Theory Fundamentals
</div>

Color is one of the most powerful tools in visual storytelling. This week, you'll learn the fundamentals of color theory and how to use color intentionally in your designs.

## Color Theory Basics

**The Color Wheel:**
- **Primary colors**: Red, Yellow, Blue (cannot be mixed from other colors)
- **Secondary colors**: Orange, Green, Purple (mix of two primaries)
- **Tertiary colors**: Red-Orange, Yellow-Green, etc. (primary + secondary)

**Color Properties:**
- **Hue**: The actual color (red, blue, green)
- **Saturation**: Intensity/purity of the color (vivid vs. muted)
- **Value**: Lightness or darkness of the color

**Color Temperature:**
- **Warm colors**: Reds, oranges, yellows (energetic, advancing)
- **Cool colors**: Blues, greens, purples (calming, receding)

## Assignment Directions

### Part 1: Color Harmony Study

Research and create examples of these color harmonies using the color wheel:
1. **Complementary**: Colors opposite on the wheel (high contrast)
2. **Analogous**: Colors next to each other (harmonious)
3. **Triadic**: Three colors evenly spaced (balanced, vibrant)
4. **Monochromatic**: Variations of one hue (unified, sophisticated)

For each harmony, find 2 examples from existing games/films and explain why it works.

### Part 2: Color Psychology Analysis

Study how color communicates emotion and meaning:
- Choose 3 different games or animated films
- Identify the dominant color palette of each
- Write 2-3 sentences explaining what emotions/themes the colors convey
- Include screenshots showing the color palettes

### Part 3: Personal Reflection

Write 150-200 words addressing:
- Which color harmonies appeal to you most?
- What colors might fit your capstone project's mood?
- How can you use color to support your narrative?

## What to Turn In

Submit to Canvas:
1. Color harmony examples with explanations (4 harmonies, 2 examples each)
2. Color psychology analysis (3 projects with screenshots)
3. Personal reflection (150-200 words)

## Grading Criteria

- **Color Harmonies** (40%): Clear examples, accurate identification
- **Psychology Analysis** (35%): Thoughtful connection between color and emotion
- **Reflection** (25%): Application to own project
