Intro to Media Careers surveys creative roles and workflows in the AME sector with focus on animation/VFX, design, and game art. Students build core digital literacy, visual storytelling, and production habits while exploring careers and preparing a starter portfolio.

{{< /callout >}}

## What We Cover

1. **Careers in Games & Media Arts**  
   Roles across art, design, programming, production, audio, writing; pipelines and key terms; map interests to animation/VFX/design; short career reflection.

2. **Core Computer & Digital Literacy for Media Careers**  
   Typing, OS navigation, file structure, backups; industry file naming and asset management; installing Blender/Krita; image formats, resolution, compression.

3. **Visual Storytelling & Game Design Fundamentals**  
   Genres, core loops, mechanics; story principles for games; composition and visual hierarchy; quick concept sketches in Krita.

4. **Game Art Foundations**  
   Color theory, silhouettes, readability; 3D space and navigation in Blender; model and export a simple prop; compare 2D vs 3D workflows.

5. **Collaborative Media Project**  
   Small-team pipeline simulation; rotating roles (concept, model, design); integrate 2D concepts into 3D mockups; structured WIP critiques.

6. **Professional Skills & Portfolio Development**  
   Personal branding and web presence; resume and portfolio curation; freelancing vs studio employment; final showcase and updated career plan.
