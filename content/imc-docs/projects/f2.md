You will design **one original prop** that belongs to your Semester 1 character. This project connects to the skills you’ve developed in Units 4–6:  
- Applying **art and design principles** to game assets (Unit 4)  
- Collaborating and presenting in a **production pipeline** (Unit 5)  
- Building your **portfolio and professional skills** (Unit 6)  

Your prop should be designed, modeled in Blender, textured (if applicable), and presented as a portfolio-ready piece. It must reflect the world, role, and personality of your character.

> [!IMPORTANT]  
> This is **not about making the most complex model possible**. It’s about showing a clear design pipeline — from concept art to 3D presentation — and documenting your process. A simple, well-thought-out prop will earn more points than an over-complicated but unfinished one.

---

# Deliverables

1. **Prop Concept & Function Doc (150–200 words)**  
   - What is the prop? (weapon, tool, personal item, environmental object)  
   - How does it connect to your Semester 1 character?  
   - What purpose does it serve in the game world?  

2. **Concept Art**  
   - 2–3 silhouette explorations of the prop  
   - Refined sketch with callouts (materials, scale, features)  
   - Final design sheet  

3. **3D Blender Model**  
   - Low-poly game-ready model  
   - Clean topology and proper naming of objects  
   - UV unwrap + basic materials  

4. **Final Render & Turntable**  
   - One polished render of the prop in Blender  
   - 360° turntable (wireframe + shaded)  

5. **Portfolio Integration**  
   - Final board combining concept + model renders  
   - Reflection paragraph on skills learned  
   - Updated portfolio page (PDF or website draft) including both your character and prop  

6. **Professional Practices**  
   - Correct file naming (`Last_First_Prop_Final_v01.blend`)  
   - Organized folder with textures, renders, and project files  
   - References credited

---

## Learning Outcomes

By completing this project, you will:  
- Demonstrate **asset creation workflow** from 2D concept to 3D model  
- Apply **Blender navigation, modeling, and export** skills  
- Present a **prop that complements your Semester 1 character**  
- Build a **portfolio-ready page** showing character + prop together  
- Practice **professional documentation and file management**

> [!NOTE]  
> This project prepares you for the next class (Game Art & Design I), where you’ll build larger environments and integrate assets into Unreal.

---

## Rubric

| Criteria | Exceeds (100%) | Meets (85%) | Approaches (55%) | Does Not Meet (0%) | Value |
|---|---|---|---|---|---:|
| **Prop Function & Doc** | Clear function, strong tie to character + world | Function described, ties to character | Weak description, unclear tie | None | 10 |
| **Concept Art** | Silhouettes + refined sheet, well-annotated | Complete with some notes | Minimal sketches, weak notes | None | 15 |
| **3D Blender Model** | Clean topology, UVs, game-ready | Model complete, basic UVs | Messy topology, errors | None | 25 |
| **Final Render & Turntable** | Polished render + clean turntable (wireframe + shaded) | Render + turntable present | Incomplete or low quality | None | 20 |
| **Portfolio Integration** | Board + reflection + updated portfolio page | Board + reflection present | Partial submission | None | 15 |
| **Process & References** | Iterations + sources credited | Some process + references | Minimal or missing | None | 10 |
| **Professional Practices** | Correct naming + organized folder | Minor errors | Frequent errors | None | 5 |

**Total: 100 points**

*Late work: −10% per week. Missing sources: −5. Poor naming: −2.*
