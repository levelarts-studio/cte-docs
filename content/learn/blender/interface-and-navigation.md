## What you'll be able to do

- Orbit, pan, and zoom fluently inside Blender's 3D Viewport.
- Toggle between Object Mode and Edit Mode using `Tab`.
- Select Vertices, Edges, and Faces using `1`, `2`, `3`.
- Move, Rotate, and Scale 3D meshes using `G`, `R`, `S`.

### 1. Viewport Controls
- **Orbit**: Hold `Middle Mouse Button` and drag.
- **Pan**: Hold `Shift + Middle Mouse Button` and drag.
- **Zoom**: Scroll `Mouse Wheel`.

### 2. Transform Keys
- **G (Grab)**: Move selected geometry.
- **R (Rotate)**: Move selected geometry.
- **S (Scale)**: Resize selected geometry.
- **Axis Constraint**: Press `X`, `Y`, or `Z` after `G`, `R`, or `S` to lock movement to a single axis.
