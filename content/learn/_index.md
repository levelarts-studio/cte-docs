# Textbook Module Library

Modules are decoupled textbook lessons organized by subject area and tier level.

## Subjects

- [Computing](/learn/computing/) — PC literacy, operating systems, hardware, file management
- [Design](/learn/design/) — Elements of art, principles of design, color theory, composition
- [Media](/learn/media/) — Narrative structure, shot framing, audio, editing, delivery
- [Career](/learn/career/) — Pathways, O*NET research, Google Sites portfolios, resumes
- [Law](/learn/law/) — Intellectual property, copyright, fair use, licensing, AI ethics
- [Production](/learn/production/) — Creative briefs, team roles, GDDs, version control, sprints
- [Blender](/learn/blender/) — 3D modeling, UV unwrapping, PBR texturing, rigging, export
- [Unreal Engine](/learn/unreal/) — Actor placement, materials, lighting, Blueprints, UI
- [Game Design](/learn/gamedesign/) — Mechanics, core loops, level design, playtesting, balance
